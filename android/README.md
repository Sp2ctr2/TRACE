# 새온은행 × TRACE — Native Android

TRACE 웹사이트의 밝은 화면과 송금 상태를 Android 앱으로 옮긴 오프라인 참조 은행입니다. 기존 사이트 파일은 수정하지 않으며 앱 코드는 `android/`에 분리합니다.

## 실행

Android Studio에서 이 폴더를 엽니다. JDK 17, Android SDK Platform 36, Build Tools 36.0.0이 필요합니다. APK의 최소 Android 버전은 8.0(API 26)이며 targetSdk는 35입니다.

```bash
# 표준 wrapper가 포함된 배포 소스 ZIP
./gradlew :domain:test :app:assembleDemoDebug
adb install -r app/build/outputs/apk/demo/debug/app-demo-debug.apk

# 저장소 checkout에서 wrapper를 아직 생성하지 않은 경우
# Gradle 8.11.1로 한 번만 생성합니다.
gradle wrapper --gradle-version 8.11.1
```

빌드에는 Maven/Google 저장소 접근이 필요하지만 **설치한 앱의 실행에는 네트워크가 필요 없습니다.** 앱 manifest에는 INTERNET 권한이 없습니다. CI는 Java/Gradle/Android 의존성을 고정하고 표준 wrapper, APK, 테스트 보고서, 실행 화면을 아티팩트로 남깁니다.

APK 패키지: `dev.sp2ctr2.saeon.demo`. 제공되는 APK는 시연용 debug 서명입니다. 운영 배포용 서명키는 생성하거나 저장소에 커밋하지 않습니다. 서로 다른 CI 빌드의 debug 서명이 다르면 기존 앱을 삭제한 뒤 설치해야 할 수 있으며, 이 경우 시연 내역이 초기화됩니다.

## 탭과 기능

- **홈:** 가상 생활통장 잔액, 송금, 적금에서 가져오기, 최근 거래, TRACE 상태, 예약, 알림.
- **자산:** 생활통장과 적금의 합계, 대출을 뺀 순자산, 계좌·카드·대출 상세.
- **송금:** 등록 수취인 검색, 마스킹 계좌 뒷자리 조회, 숫자판, 금액·목적 수정, 검토, 명시적 시연 인증 또는 기기 인증, 정책 결과와 영수증.
- **안전:** 위험 신호, 시간 순서, 보류된 거래, 확인할 다음 행동, 텍스트 공유·입력 분석, 개인정보 경계.
- **전체:** 프로필, 인증, 1회 한도, 자주 쓰는 계좌, 예약 관리, 쉬운 모드, 전환 줄이기, 진동, 홈 잔액 숨김, 고객지원 시연, 앱 정보.

내역·검색·필터·설정·예약은 로컬 데이터에 반영됩니다. 표시된 은행, 고객, 계좌, 대출, 거래는 모두 가상입니다.

## 시연 제어

**전체 탭 맨 아래 TRACE 버전 행을 길게 누르거나 5회 누릅니다.** TalkBack에는 길게 누르기 동작의 이름이 제공됩니다. 시연 제어는 외부 딥링크나 intent extras로 노출하지 않습니다.

선택 후 초기화 확인을 누르면 잔액, 내역과 위험 신호가 해당 시나리오로 다시 만들어집니다.

| 상황 | 수취인 | 금액 | 결과 |
|---|---|---:|---|
| 정상 송금 | 이서연 · 노을은행 7421 | 32,000원 | ALLOW → 완료 |
| 기관 사칭 | 김○○ · 노을은행 9802 | 3,000,000원 | HOLD |
| 대출 상환 | 박○○ · 노을은행 5934 | 8,000,000원 | VERIFY → 공식 계좌 → 새 검토 → 완료 |
| 조회 실패 | 박○○ | 8,000,000원 | UNKNOWN, 출금 없음 |
| 추가 확인 | 이서연 | 32,000원 | WARN → 재검토 → 완료 가능 |

공식 상환 계좌는 `새온은행 대출상환센터 · 200-***-3014`입니다. 경로 조회 자체는 거래 승인이 아닙니다. 수취인이 바뀌면 거래 ID가 새로 만들어지고 다시 검토해야 합니다. 조회 실패는 일반 송금으로 전환하지 않습니다.

초기 생활통장 12,840,000원, 적금 2,400,000원, 대출 8,000,000원입니다. 따라서 보유 자산은 15,240,000원, 순자산은 7,240,000원입니다. 카드 이용 금액을 자산에 더하지 않습니다. 초기 거래 내역과 기초 잔액을 합치면 생활통장 잔액과 정확히 일치하도록 구성했습니다.

## 구조

```text
domain/
  Models / Fixtures
  BankEngine           순수 정책 · 거래 연결 · 원장 불변조건
  LocalRiskAnalyzer    공개된 로컬 규칙, ML 모델 아님
  BankEngineTest       정책 · 서명 변조 · 중복 · 만료 · 원장 회귀
app/
  data/                Room 원장 aggregate, Mutex + DB transaction, DataStore
  security/            Android Keystore P-256 / SHA256withECDSA
  BankViewModel        UDF, StateFlow, 사용자 명령 처리
  ui/                  라이트 디자인 토큰, 은행·송금·안전·설정 화면
  androidTest/         실제 Compose 탐색 / 에뮬레이터 화면 캡처
```

거래, 잔액, 영수증을 Room의 단일 aggregate에 원자적으로 기록합니다. UI는 영수증을 만들거나 잔액을 직접 수정하지 않습니다. 서명은 수취인·계좌·금액·목적·거래 ID·초기화 epoch와 유효기간을 연결합니다. Commit 시 현재 정책을 다시 평가하고, 기존 거래 ID는 두 번 차감하지 않습니다.

분석 중 앱이 중단되면 자동 완료하지 않고 검토 상태로 돌아갑니다. HOLD는 영속 보관하며, 화면 닫기·취소·신호 만료·프로세스 재생성으로 해제하지 않습니다. 이 참조 구현의 보류 해제는 일반 사용자 UI에 제공하지 않습니다. Demo Lab의 명시적 전체 초기화는 별도의 시연 제어입니다.

## 개인정보와 기능 경계

`ACTION_SEND`의 text/plain을 받으면 먼저 편집·확인 화면을 표시합니다. 입력 원문은 Room, DataStore, saved instance state, 로그에 넣지 않습니다. 사용자가 분석을 누르면 정해진 위험 유형, 시간, 출처와 정리된 설명을 만들고 입력 원문을 지웁니다. 링크에 실제 접속하거나 문자함·통화를 수집하지 않습니다.

이번 앱은 **규칙 기반 참조 구현**입니다. 임의 문장에 대한 탐지 정확도나 보이스피싱 전면 차단을 주장하지 않습니다. 위험 신호가 없다는 결과도 안전 보증으로 표현하지 않습니다. 은행 게이트웨이도 기기 안에서 동작하므로 네트워크가 없다고 실제 은행 조회를 했다고 표시하지 않습니다.

Keystore private key는 앱이 내보내지 않습니다. 그러나 같은 앱 내부의 정책 검증은 독립된 은행 서버, 금융기관 운영 통제, 원격 하드웨어 attestation을 대신하지 않습니다. 이 APK를 실제 금융 인증·송금 서버로 사용해서는 안 됩니다.

예약은 로컬 예약 정보 관리이며, 운영 은행의 자동 송금 스케줄러가 아닙니다. 고객지원도 상담 내용을 정리하는 시연이며 실제 상담원 접수나 경찰 신고를 하지 않습니다. 음성 입력, 문자/통화 자동 감시, 실제 계좌 조회, 실물 카드 발급은 포함하지 않습니다. 기본 한국어 글꼴은 기기 기본 글꼴을 사용합니다.

## 검증

```bash
./gradlew :domain:test

```

GitHub Actions는 Android 35 에뮬레이터에서 Wi-Fi와 모바일 데이터를 끄고 UI 테스트를 실행합니다. 같은 자동화 스위트를 두 번 실행하고 각 패스의 보고서와 PNG를 별도로 보관합니다. 실제 통과 여부는 해당 commit의 CI 결론과 보고서를 확인해야 합니다.

`07_evaluating.png`는 순간적으로 지나가는 실제 Native 진행 화면에 테스트 상태를 주입해 캡처한 것입니다. 처리시간 측정이나 AI 추론 증거가 아닙니다. 다른 거래 결과 화면은 UI의 실제 송금 경로를 통해 생성됩니다.

자동화된 semantics/대형 글꼴 검사는 실제 TalkBack 사용자 평가와 같지 않습니다. 테스트가 통과해도 모든 기기에서 결함이 없다는 보증은 하지 않습니다. 실제 검증 기기, 보고서와 남은 제약은 전달된 검증 보고서에 따릅니다.
