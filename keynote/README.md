# TRACE · Mentoring Keynote

2026.10.02 · 본인 인증, 그다음.

TRACE의 발표, 기술 질의응답, 멘토링 기록을 위한 정적 웹 키노트입니다. 기존 홈페이지와 분리된 `keynote/` 경로를 사용합니다. 외부 JavaScript 라이브러리, 원격 폰트, API 키 또는 AI API가 필요하지 않습니다.

## 바로 사용하기

`index.html`을 브라우저로 열거나 GitHub Pages의 `/TRACE/keynote/`에 접속합니다. 전체 18장과 핵심 9장 경로를 하단에서 선택할 수 있습니다. 발표 시작 전에 전체 화면과 발표자 창을 열고 팝업 허용 여부를 확인하세요.

| 키 | 기능 |
| --- | --- |
| → / Space | 다음 장면 |
| ← / Shift+Space | 이전 장면 |
| Q / Ctrl·Cmd+K | 질문 검색 |
| M | 전체 장면 지도 |
| P | 발표자 창 |
| N | 멘토링 기록 |
| F | 전체 화면 |
| T | 타이머 시작·일시정지 |
| B | 화면 가리기·복귀 |
| Esc | 질문·도구 창 닫기 |
| ? | 사용법 |

질문 창에서는 ↑·↓로 답변을 고르고 Enter로 본문에 이동합니다. 관련 설명 장면으로 이동한 뒤 하단의 **발표로 복귀**를 누르면 원래 장면으로 돌아갑니다. 휴대폰에서는 좌우 스와이프 또는 하단 화살표를 사용합니다.

## 발표자 화면

발표자 창은 대본, 다음 장면, 관련 질문, 타이머와 장면 제어를 제공합니다. 같은 브라우저·출처의 발표 창과 BroadcastChannel로 연결하며, 지원되지 않는 환경에서는 localStorage 이벤트를 사용합니다. 온라인 배포 주소에서 사용하는 것이 권장됩니다. 브라우저의 로컬 파일 보안 정책에 따라 오프라인 파일의 창 연결·저장 기능이 제한될 수 있습니다.

화상 멘토링에서는 **관객용 발표 창만 공유**하세요. 전체 데스크톱을 공유하면 발표자 대본이나 메모가 노출될 수 있습니다.

## 질문과 기록의 범위

61개 항목은 미리 작성된 답변집의 로컬 검색입니다. 자유 생성형 챗봇이 아니며 등록되지 않은 질문의 답을 만들어 내지 않습니다. 각 항목에는 짧은 답변, 상세 설명, 주의할 주장, 근거 범위와 관련 장면이 있습니다.

메모는 현재 브라우저의 localStorage에만 저장합니다. 저장이 제한되면 열린 페이지의 메모리에 유지합니다. 서버 전송이나 기기 간 동기화는 없습니다. 브라우저 데이터 삭제·저장 제한에 대비해 Markdown으로 내보내세요. 공유 기기에서는 사용 후 내보내기와 기록 삭제를 권장합니다.

## 자료 기준

- 구조·책임 경계는 보관된 2026.09.28~29 문서와 구현 보고의 범위입니다. 최신 개발 환경의 재실행·재감사 보고서가 아닙니다.
- 원본 학습 조건 100%, 블라인드 약 94%·82%는 2026.10.02 개발자 보고입니다. 평가 표본, metric 정의, 모델 식별자와 독립성 확인 전에는 실전 정확도나 동일 조건의 직접 비교로 해석하지 않습니다.
- 300만 원 사례와 역할 전환은 설명용 가상 시나리오입니다. 실제 TRACE 모델 또는 은행 API를 호출하지 않습니다.
- 실은행 도입 완료, 개인정보 무유출, 모든 공격 차단, 제품 출시 승인을 주장하지 않습니다.
- `noindex`는 검색 노출 억제 요청일 뿐 접근 제어가 아닙니다. 이 GitHub Pages 사이트와 원본 코드는 공개됩니다. 개인정보·비밀키·비공개 학습 데이터를 추가하지 마세요.

빌드 도구 없이 배포할 수 있습니다. 현재 저장소의 기존 Pages workflow가 `main`의 루트 전체를 배포하므로 이 폴더 변경도 함께 반영됩니다. 캐시로 이전 내용이 보이면 HTML의 자산 버전 문자열을 올리세요. 시스템 폰트를 사용하므로 기기별 글꼴은 달라질 수 있습니다.
